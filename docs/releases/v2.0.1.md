This release remembers your **Flat / Hierarchical** session view and updates frontend dependencies to resolve HIGH-severity security advisories.

## Session Navigator preferences

- Save the selected **Flat** or **Hierarchical** view on this device and restore it when the app reopens.
- Load the restored Hierarchical view from the newly discovered session snapshot.
- Use Flat when no valid saved choice is available.
- Keep view switching available if the choice cannot be saved, with a warning in Status.

## Dependency security

- Update **Vite** from 8.0.16 to 8.1.6, **devalue** from 5.9.2 to 5.9.4, and **source-map-js** from 1.2.1 to 1.2.2, together with the required Vite dependencies.
- Resolve the three HIGH-severity package findings reported by `npm audit`; the updated dependency graph reports **zero known vulnerabilities** at release verification.
- These updates cover development, build, and Svelte server-rendering dependencies. The desktop app continues to use a bundled client-rendered frontend.

## Verification and compatibility

- Add regression coverage for saved view restoration, invalid values, and storage failures, including app remounts in a real browser.
- Keep original JSONL records, transcript order, Collection behavior, and the Worklog export format unchanged.

This remains a **portable Windows x64 release** with no installer or automatic update behavior.

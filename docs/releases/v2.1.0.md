This release adds **Session / Transcript search** and moves action feedback from the Status row into **Toasts**. Find past user requests across local sessions, or highlight and navigate matching content in the current transcript.

## Session search

- Search the complete Session Navigator snapshot, including sessions beyond the pages currently loaded in the list. Support both plain `.jsonl` and compressed `.jsonl.zst` records.
- Match only actual **YOU** messages using the existing parser's classification. Codex responses, tool calls, tool results, and metadata are excluded.
- Show matching sessions and their result count while retaining **Flat / Hierarchical** views, ordering, paging, and session selection.
- Keep the existing discovery boundary under `CODEX_HOME/sessions`, including the existing exclusions for archives, Guardian reviews, and linked sources.
- Report progress, completion, and unreadable files through Toasts. Ignore superseded searches so older results cannot replace a newer search.
- Submit an empty Session query to restore the complete list. **Reload Sessions** discovers current files and reapplies the last submitted query.

## Transcript search

- Search rendered message bodies that pass the current **Filters**. Collapsed bodies become searchable when expanded.
- Highlight matches, scroll to the active result, and show the current position and total count. Repeating the same search advances to the next result and wraps after the last match.
- Match displayed Markdown text across inline formatting while preserving line and paragraph boundaries. Keep existing message nodes, link behavior, and Collection snapshots intact.
- Recompute results after filter, collapse, Refresh, theme, or session changes using the last submitted condition. Search preserves the existing filters and Collection state.
- Submit an empty Transcript query to clear its highlights and result position.

## Shared SEARCH controls

- Replace the header's Status row with **SEARCH**, a **Session / Transcript** selector, a query input, and a magnifying-glass button.
- Keep one shared input across scope changes, with separate last-applied conditions and results for Session and Transcript. Editing or deleting the input, or switching scope, preserves existing results and highlights.
- Apply the input only when **Enter** or the magnifying-glass button is used. Searches use literal, case-insensitive substrings and ignore surrounding query whitespace.
- Use **Ctrl+F** to focus the Observatory input and select its existing text while retaining the chosen scope, in place of WebView2's default Find UI.
- Reserve a fixed result area with room for **999 / 999**, keeping the input width stable as counts change. Preserve the **44px** header row and the three-panel layout.

## Toast feedback

- Show action results, progress, warnings, and errors at the bottom right, above the workspace. Hide the idle `Ready.` message.
- Distinguish **Success**, **Info**, **Progress**, **Warning**, and **Error** with status icons and accent colors. Progress uses an animated loading icon and respects reduced-motion preferences.
- Use dark Toasts for **Terminal Style / DM Style (Dark)** and light Toasts for **Markdown Style / DM Style**. Apply theme changes immediately to visible notifications.
- Use compact **360px** cards with a close button. Allow long errors to wrap and scroll while keeping the panel layout unchanged.
- Dismiss Info and Success after **4 seconds**, Warning after **8 seconds**, and Error after **12 seconds**. Keep active Progress visible until completion, and pause automatic dismissal during mouse or keyboard inspection.
- Preserve status priority, request tokens, and stale-response protection across copying, loading, search, and export operations.

## Verification and compatibility

- Pass the complete automated verification: **76 frontend unit tests**, **25 browser integration tests**, **164 backend tests**, and **10 Tauri tests**, together with static checks and production builds. Two existing tests that require private local logs remain opt-in.
- Verify Session and Transcript search, filter updates, result navigation, and Ctrl+F in the Windows app using synthetic session records.
- Synchronize application versions and Windows executable metadata at **2.1.0**. Remove the trailing period from the Terminal `[OK] Latest public version` notice while preserving public-release comparison behavior.
- Keep original JSONL records, transcript order, Collection copying, and the Worklog export format unchanged. Search runs locally without a persistent index or external search service.

This remains a **portable Windows x64 release** with no installer or automatic update behavior.

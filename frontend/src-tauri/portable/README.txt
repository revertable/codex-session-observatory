Codex Session Observatory - Portable Windows Build
================================================

English
-------

Extract the ZIP, then run codex-session-observatory.exe.
Use Select JSONL to open a session from Codex CLI or the Codex Windows app.

- Transcript: choose a theme and role filters; click headers to collapse messages.
- Capture Transcript: copy the current filtered, themed, collapsed text view.
- Collection: use +/✓ to select messages, then Copy All to copy them in original
  transcript order. Clear resets selections. Refresh keeps them; another file
  or closing the app clears them. The panel shows read-only raw message text.
- Export Worklog: save the complete session as structured local files,
  independently of filters or Collection selections.

The app processes session files locally and leaves them unchanged.
This build is unsigned; Windows may display a publisher warning.

Official releases:
https://github.com/revertable/codex-session-observatory/releases


한국어
------

ZIP 압축을 풀고 codex-session-observatory.exe를 실행하세요.
Select JSONL로 Codex CLI나 Codex Windows 앱의 세션을 엽니다.

- Transcript: 테마와 역할 필터를 선택하고, 헤더를 클릭해 메시지를 접습니다.
- Capture Transcript: 현재 필터·테마·접기 상태를 반영한 대화를 복사합니다.
- Collection: +/✓로 메시지를 선택하고 Copy All로 원본 출현 순서대로 복사합니다.
  Clear는 선택을 비웁니다. Refresh는 선택을 유지하며, 다른 파일을 열거나
  앱을 닫으면 초기화됩니다. 패널은 읽기 전용 원문 텍스트를 표시합니다.
- Export Worklog: 필터나 Collection 선택과 관계없이 전체 세션을
  구조화된 로컬 파일로 저장합니다.

앱은 세션 파일을 로컬에서 처리하며 원본을 변경하지 않습니다.
이 빌드는 서명되지 않았으며 Windows에서 게시자 경고가 표시될 수 있습니다.

공식 릴리스:
https://github.com/revertable/codex-session-observatory/releases
